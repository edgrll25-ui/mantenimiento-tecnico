# 🛠️ Sistema de Gestión de Incidencias - TecnoSoluciones

Este proyecto es una plataforma web estática diseñada para una empresa de mantenimiento informático. Permite a los usuarios visualizar la información corporativa y reportar averías técnicas a través de un formulario detallado.

## 🚀 Características principales

* **Identidad Corporativa:** Cabecera con logotipo, datos fiscales (NIF) y menú de navegación.
* **Formulario de Incidencias:** Recogida de datos del cliente, especificaciones del equipo (S.O., modelo) y selección de componentes afectados.
* **Niveles de Urgencia:** Clasificación de tickets (Baja, Media, Alta/Crítica).
* **Diseño Profesional:** Pie de página con redes sociales, política de privacidad y horarios de atención.

## 🛠️ Tecnologías utilizadas

* **HTML5:** Estructura semántica y formularios validados.
* **CSS3:** Diseño responsivo y estilización profesional.
* **GitHub Pages:** Hosting gratuito para la visualización del proyecto.
